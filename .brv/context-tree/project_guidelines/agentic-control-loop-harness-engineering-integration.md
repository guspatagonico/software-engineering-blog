# Agentic Control Loop & Harness Engineering Integration

The project implements a formal control-theory approach (Harness Engineering) to manage agentic 'drift', which manifests both as an architectural constraint for sub-agents and as a specialized UI component for blog interactivity.

## Evidence

- **project_guidelines**: The Envolvente Convergente framework uses Lyapunov and Barrier functions to ensure agent actions monotonically decrease distance to objectives, triggered by 'drift signals'.
- **ui**: The Harness Agentic Control system features an SVG-based 'Drift Map' with slider filtering and Evidence Cards to visualize these control states.
